# 🐳 Portainer

Portainer is a powerful container management interface that allows you to easily manage your Docker, Swarm, and Kubernetes environments through a clean, intuitive web UI.

## 🚀 Key Features
- **Visual Management**: Manage containers, images, networks, and volumes without touching the CLI.
- **Stacks**: Deploy and manage multi-container applications using Docker Compose.
- **Console Access**: Open a shell directly into any running container from your browser.
- **Logs**: Easily view and search container logs for troubleshooting.

## 🛠️ Setup
- **Web Interface**: Access at `https://<SERVER-IP>:9443` (Default HTTPS) or the HTTP port defined in your compose.
- **Persistence**: Ensure the `/data` volume is backed up as it contains all Portainer configuration.
