# 🏠 Homarr

Homarr is a simple, lightweight, and customizable dashboard for your home server. It unifies all your services into a single point of access.

## 🚀 Key Features
- **Widget-based**: Integrate with Plex, Sonarr, Radarr, and more via interactive widgets.
- **Privacy First**: Everything is stored locally on your server.
- **Customizable**: Drag-and-drop interface to design your perfect layout.
