# 🎬 Plex Media Server

Plex is the ultimate media streaming platform that organizes your personal collection of movies, TV shows, music, and photos, making them accessible on any device, anywhere.

## 🚀 Key Features
- **Centralized Library**: Beautifully organizes your media with metadata, posters, and trailers.
- **Cross-Platform**: Apps available for Smart TVs, mobile devices, consoles, and web browsers.
- **Remote Access**: Stream your content outside your home network securely.
- **Hardware Acceleration**: Efficient transcoding using GPU (requires Plex Pass).

## 🛠️ Configuration
- **Transcoding**: Configure your `/transcode` volume to a fast SSD or RAM disk (`/dev/shm`) to improve performance.
- **Ports**: Defaults to port `32400`.
- **Claim Token**: Ensure you use a `PLEX_CLAIM` token for the initial setup to link the server to your account.
