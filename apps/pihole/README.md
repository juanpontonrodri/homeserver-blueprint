# 🛡️ Pi-hole

Pi-hole is a network-wide ad blocker that acts as a DNS sinkhole, protecting your devices from advertisements and tracking without requiring any client-side software.

## 🚀 Key Features
- **Network-wide Protection**: Block ads on every device in your home (Smart TVs, mobile, etc.).
- **Performance**: Improved network performance as ads are blocked before they are downloaded.
- **Privacy**: Reduces tracking scripts and analytics from reaching your devices.
- **Intuitive Dashboard**: Web interface to monitor queries, manage blocklists, and view statistics.

## 🛠️ Setup
1. **DNS Configuration**: Set your router's DNS to the IP of your home server where Pi-hole is running.
2. **Web Admin**: Access the dashboard at `http://<SERVER-IP>:18080/admin`.
3. **Blocklists**: Add custom "Adlists" to enhance blocking (e.g., from Firebog).
