# 📄 Stirling-PDF

Stirling-PDF is a powerful, self-hosted web-based PDF manipulation tool. It allows you to perform various operations on PDF files without your data ever leaving your server.

## 🚀 Key Features
- **Full Privacy**: Your files never leave your server; everything is processed locally.
- **Merge & Split**: Combine multiple PDFs or split them into individual pages.
- **Conversion**: Convert images to PDF, PDF to Word/PowerPoint/Image, and more.
- **Security**: Add or remove passwords, watermarks, and edit metadata.
- **OCR**: Optical Character Recognition to make scanned PDFs searchable.
- **Page Management**: Rotate, reorder, delete, and crop pages.

## 🛠️ Setup
- **Web Interface**: Accessible on port `12532`.
- **Image Type**: Uses the `latest-fat` image which includes all dependencies for OCR and advanced conversions.
- **Customization**: App name and descriptions can be customized via environment variables like `UI_APPNAME`.
