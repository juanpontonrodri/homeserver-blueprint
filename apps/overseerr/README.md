# 🎫 Overseerr

Overseerr is a request management and media discovery tool built to work with your existing Plex ecosystem. It provides a beautiful interface for users to discover and request content.

## 🚀 Key Features
- **Plex Integration**: Syncs with your Plex library and users.
- **Auto-Request**: Automatically sends requests to Sonarr and Radarr.
- **User Management**: Grant permissions to different users for requesting content.
- **Notifications**: Notifies users when their media is available via email, Discord, or Pushbullet.

## 🛠️ Setup
1. **Connect Plex**: Link your Plex account and server.
2. **Connect Arrs**: Add your Radarr and Sonarr instance details and API keys.
3. **Authentication**: Users can sign in using their Plex accounts.
