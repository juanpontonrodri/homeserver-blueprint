# 📚 Audiobookshelf

Audiobookshelf is a self-hosted audiobook and podcast server. It provides a beautiful interface for managing and listening to your collection.

## 🚀 Key Features
- **Multi-user Support**: Independent progress tracking for each user.
- **Podcast Hosting**: Host your own podcasts or import existing ones.
- **Mobile Apps**: Works with dedicated apps for iOS and Android.
