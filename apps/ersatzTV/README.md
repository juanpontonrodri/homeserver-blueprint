# 📺 ErsatzTV

ErsatzTV is a specialized tool that allows you to create your own "live" linear IPTV channels using your local media library. It acts as an IPTV server that you can plug into Plex, Jellyfin, or any IPTV player (like TiviMate).

## 🚀 Key Features
- **Custom Scheduling**: Arrange movies, shows, and clips into a timed 24/7 schedule.
- **Transcoding**: Real-time transcoding to ensure compatibility with your players.
- **Plex Integration**: Can automatically import your Plex library and appear as a "Tuner" device in Plex.
- **Filler Content**: Support for "commercials" or short clips between main shows.

## 🛠️ Setup
1. **Source Media**: Define your local files or connect via Plex/Jellyfin/Emby.
2. **Channels**: Create virtual channels with specific names and logos.
3. **Playouts**: Assign schedules to your channels.
