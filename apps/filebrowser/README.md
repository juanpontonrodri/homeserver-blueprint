# 📂 File Browser

File Browser is a sleek, web-based file management interface that allows you to manage your server's filesystem from any browser. It provides a user-friendly way to upload, download, delete, and organize files.

## 🚀 Key Features
- **Intuitive Web UI**: Manage your files with an interface similar to modern operating systems.
- **Multiple Users**: Create different users with specific permissions and home directories.
- **Search & Filtering**: Quickly find files using global search and filters.
- **Real-time Previews**: Preview images, videos, and documents directly in the browser.
- **Share Links**: Create public links to share files and folders with others.
- **Command Runner**: Execute commands directly on your files from the web interface.

## 🛠️ Setup
- **Web Interface**: Accessible on port `13678`.
- **Root Directory**: This instance is configured to view the entire host filesystem (starting from `/`) mounted at `/srv`.
- **Persistence**: User accounts and settings are stored in the `./database` directory.
