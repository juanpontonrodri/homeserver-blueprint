# 🎬 Bazarr

Bazarr is a companion application to Sonarr and Radarr. It manages and downloads subtitles based on your requirements. You define your preferences by TV show or movie and Bazarr takes care of everything for you.

## 🚀 Key Features
- **Automatic Subtitle Selection**: Downloads the best matching subtitles for your media.
- **Support for Multiple Providers**: Integrates with OpenSubtitles, Podnapisi, Addic7ed, and many more.
- **Manual Search**: If the automated process fails, you can manually select from a list of available subtitles.
- **Subtitle Translation**: Can translate subtitles using various translation engines.

## 🛠️ Setup & Integration
1. **Connect to Sonarr/Radarr**: Go to `Settings > Radarr/Sonarr` and enter your API keys and host mapping.
2. **Languages**: Define your "Profile" of required languages (e.g., English, Spanish).
3. **Providers**: Add your accounts for subtitle providers (many require free registration).
