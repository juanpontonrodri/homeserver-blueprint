# 📰 Miniflux

Miniflux is a minimalist and opinionated feed reader (RSS, Atom, JSON). It is designed for simplicity, speed, and privacy.

## 🚀 Key Features
- **Minimalist UI**: Clean, clutter-free reading experience.
- **Fast and Efficient**: Optimized for speed and low resource usage.
- **Privacy Focused**: No tracking, no external dependencies, and self-hosted.
- **OPML Export/Import**: Easily move your feeds in and out.
- **Mobile Friendly**: Great experience on mobile devices via web or third-party apps.

## 🛠️ Setup
- **Admin Setup**: The initial admin user is created via the `ADMIN_USERNAME` and `ADMIN_PASSWORD` environment variables.
- **Database**: Uses a dedicated PostgreSQL instance.
- **Port**: Accessible on port `8881`.
