# 📸 Immich

Immich is a high-performance self-hosted backup solution for photos and videos directly from your mobile phone. It is designed to be a fast, feature-rich alternative to Google Photos.

## 🚀 Key Features
- **Mobile Backup**: Seamlessly back up photos and videos from iOS and Android.
- **AI-Powered**: Includes facial recognition, object detection, and CLIP-based search.
- **Multi-user Support**: Share albums and libraries with family and friends.
- **Map View**: Visualize your media based on location metadata.
- **High Performance**: Built with TypeScript, NestJS, and PostgreSQL for speed.

## 🛠️ Setup
- **Upload Location**: Define your `UPLOAD_LOCATION` in the `.env` file to point to your storage disk.
- **Machine Learning**: This instance uses OpenVINO for hardware-accelerated AI inference.
- **External Libraries**: You can mount existing folders (like `/media/fotos`) as read-only external libraries.
