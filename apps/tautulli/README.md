# 📊 Tautulli

Tautulli is a web application for monitoring, analytics, and notifications for your Plex Media Server.

## 🚀 Key Features
- **Statistics**: Provides detailed statistics on what has been watched, who watched it, when, and where.
- **Real-time Monitoring**: See what is currently being streamed on your server.
- **Notifications**: Send alerts to Discord, Telegram, Slack, or email when new content is added or when someone starts watching.
- **History**: Keeps a full history of all plays on your server.

## 🛠️ Setup
1. **Plex Connectivity**: You will need to provide your Plex URL and an authentication token or sign in via Plex.tv within the Tautulli interface.
2. **Logs**: Ensure Tautulli can read your Plex logs for more detailed data.
