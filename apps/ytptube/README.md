# 📹 YTPTube

YTPTube is a web-based interface for downloading videos from YouTube and many other sites using the powerful `yt-dlp` backend.

## 🚀 Key Features
- **Web Interface**: Easy to use UI for searching and downloading videos.
- **Multiple Formats**: Choose between video, audio-only, and different quality levels.
- **Playlist Support**: Download entire playlists with a single link.
- **Post-Processing**: Automatic conversion and metadata embedding.

## 🛠️ Usage
1. Open the web interface at `http://<SERVER-IP>:8081`.
2. Paste the URL of the video or playlist you want to download.
3. Select the desired quality and format.
