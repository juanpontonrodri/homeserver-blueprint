# 📝 HedgeDoc

HedgeDoc (formerly CodiMD) is a self-hosted, open-source, collaborative, real-time markdown editor. It allows multiple people to edit the same document simultaneously while seeing the rendered result instantly.

## 🚀 Key Features
- **Real-time Collaboration**: Edit documents together with multiple users at once.
- **Markdown Support**: Full support for standard and extended Markdown syntax.
- **Publish & Share**: Easily share notes with others via a simple URL.
- **Slide Mode**: Transform your markdown notes into presentation slides automatically.
- **Version History**: Keep track of changes and restore previous versions.

## 🛠️ Setup
- **Domain Configuration**: Set the `CMD_DOMAIN` to your intended URL (e.g., `md.example.com`).
- **Database**: This instance is configured to use **SQLite** for simplicity, with the database stored in the `./config` directory.
- **Authentication**: Supports various OAuth providers (Google, GitHub, etc.) which can be configured via environment variables.
